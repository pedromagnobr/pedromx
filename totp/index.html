Ajuste de horário

Se o PC estiver 11 segundos atrasado, informe 11. Valores negativos atrasam o horário usado no cálculo.

Os códigos são calculados neste navegador. Sem PIN, as chaves ficam sem criptografia no navegador. Com o PIN ativo, ficam criptografadas no disco e exigem o PIN para abrir. A chave fica somente na memória; o bloqueio acontece pelo botão Trancar, após 5 minutos sem interação ou ao recarregar/fechar a página. O PIN curto ainda permite tentativas offline se alguém copiar o armazenamento. A senha do backup Aegis não é guardada. Se esquecer o PIN de bloqueio, os dados locais não poderão ser recuperados; mantenha um backup externo. Os arquivos exportados usam suas próprias senhas.

Como configurar a Calculadora TOTP

Importe um backup JSON do Aegis para adicionar suas contas. Os códigos são calculados neste dispositivo; use Copiar para o código atual ou Próximo para o próximo período.

Em Configurar, escolha o formato do relógio, a Cor de destaque, o fundo e o modo AMOLED. Ajustar atraso corrige diferenças no horário usado nos códigos.

Use Configurar PIN para proteger os dados locais, Alterar PIN para trocá-lo e Remover PIN para desativar essa proteção. O bloqueio ocorre ao clicar em Trancar, após 5 minutos sem interação ou ao fechar/recarregar a página.

Exportar configuração reúne contas, ordem, descrições, ajuste de horário, aparência, formato do relógio e proteção por PIN em um arquivo criptografado. Guarde a senha do arquivo e o PIN. Em outro dispositivo, use Importar configuração e informe ambos, quando solicitados.

Exportar backup gera um arquivo compatível com Aegis, contendo as contas; as preferências desta página são incluídas apenas na configuração. Mantenha uma cópia externa: o armazenamento do navegador pode ser apagado.

Remover PIN

As contas serão mantidas, mas ficarão sem criptografia no armazenamento deste navegador.
